# 日期解析器 `resolve_date_range.py`

## 支持的输入格式

### 标准关键词

| 输入（大小写/空格不敏感） | 输出范围 | 说明 |
|---------------------------|----------|------|
| `本周` / `这周` / `this week` | 本周一 ~ 今天 | 周一起始 |
| `上周` / `上一周` / `last week` | 上周一 ~ 上周日 | 完整上一周 |
| `本月` / `这个月` / `this month` | 本月1号 ~ 今天 | 当月起始 |
| `上月` / `上个月` / `last month` | 上月1号 ~ 上月最后一天 | 完整上个月 |
| `本季度` / `这个季度` / `this quarter` | 季度第一天 ~ 今天 | 按自然季度 |
| `上季度` / `上个季度` / `last quarter` | 上季度第一天 ~ 最后一天 | 完整上季度 |
| `今年` / `本年` / `this year` | 1月1日 ~ 今天 | 年初至今 |
| `去年` / `上年` / `last year` | 去年1月1日 ~ 12月31日 | 完整去年 |

### 相对月 + 具体日

| 输入 | 输出范围 | 说明 |
|------|----------|------|
| `上个月12号到现在` | 上月12日 ~ 今天 | 阿拉伯数字 |
| `上个月十二号到现在` | 上月12日 ~ 今天 | 中文数字 |
| `上月5号至今` | 上月5日 ~ 今天 | "至今"同义 |
| `本月10号到现在` | 本月10日 ~ 今天 | 当月截取 |
| `上个月12号` | 上月12日 ~ 月末 | 不带"到现在"→到月末 |
| `上月5号` | 上月5日 ~ 月末 | 同上 |
| `上个月到现在` | 上月1日 ~ 今天 | 不带日号→整月至今天 |
| `本月到现在` | 本月1日 ~ 今天 | 同上 |
| `上月至今` | 上月1日 ~ 今天 | 同上 |

### 中文日期

| 输入 | 输出范围 | 说明 |
|------|----------|------|
| `6月1号到6月7号` | 今年6月1日 ~ 6月7日 | 阿拉伯数字月日 |
| `六月一号到六月七号` | 今年6月1日 ~ 6月7日 | 全中文数字 |
| `5月12号到现在` | 今年5月12日 ~ 今天 | 单日起始至今 |
| `六月十二号至今` | 今年6月12日 ~ 今天 | 中文数字 + 至今 |

### 标准格式

| 输入 | 输出 |
|------|------|
| `2026-06-01 ~ 2026-06-07` | 2026-06-01 ~ 2026-06-07 |
| `2026-06-01` | 2026-06-01（单日） |

## 用法

```bash
python resolve_date_range.py "上个月12号到现在" --json
# → {"start": "2026-05-12", "end": "2026-06-12", ...}
```

解析失败时 `start` / `end` 为空字符串。

## Agent 使用指南

**只使用脚本支持的标签，不要自行编造。** 如果用户说了不支持的表述，必须转换为支持的等价标签：

| 用户说的 | Agent 应转换为 |
|---------|---------------|
| 最近一周 / 最近7天 | `本周` |
| 最近一个月 / 最近30天 | `本月` |
| 近3天 / 近5天 | 用 `--start-date`/`--end-date` 指定具体日期 |
| 上上周 | `--weeks 2` |
| 上上月 | `--date-label "上月"` 再偏移（或 `--start-date`/`--end-date`） |
| 最近半年 | 用 `--start-date`/`--end-date` 指定 |
| 过去两周 | 用 `--start-date`/`--end-date` 指定 |

**核心原则：** 先用 `--help` 确认支持列表，能直接传标签就传标签，不能则转换为 `--start-date`/`--end-date`。
